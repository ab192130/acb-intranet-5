## Planlaşdırılan sənədlər

Aşağıdakı modullar üçün ssenari sənədləri hələ yaradılmayıb; hər biri ayrıca
`docs/use-cases/*.md` faylı kimi əlavə olunacaq:

- Works tabı — work item axını, board, filtr, asılılıqlar
- Resources tabı — sənəd, use case, data dictionary
- People — kataloq və şəxs profili
- Version / activity — müqayisə və audit axını
