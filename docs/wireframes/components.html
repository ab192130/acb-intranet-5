Komponent kiti

shadcn anatomiyası · rough.js + Kalam

Gələcək wireframe-lər üçün referans. Bütün nümunələr core.js-dəki WF.ui qatı ilə çəkilir: həndəsə rough: 0.8 (shadcn anatomiyası, əl çəkməsi), mətn Kalam, palitra C.*-dir. Mövcud lo-fi səhifələr dəyişmir — yeni səhifələr birbaşa WF.ui.* çağırışları ilə qurulur.

Necə istifadə: səhifədə core.js-i qoş, sonra WF.ui.button(...), WF.ui.tabs(...), WF.ui.card(...) kimi çağırışlar et. Anatomiya bölmələrində hər komponentin hissələri və API nümunəsi var. Canlı tətbiq: Layihə icmalı →

Button

Anatomiya: Container + Label. Variant: default, secondary, outline, ghost, destructive, link. Ölçü: sm 32, default 36, lg 40, icon 36×36. Vəziyyət: hover, focus ring, disabled.

WF.ui.button(f, 72, 192, 120, 'Yadda saxla');
WF.ui.button(f, 320, 192, 88, 'Bax', { variant: 'outline' });

Badge

Anatomiya: Pill + Label. Status üçün 4 variant: default, secondary, outline, destructive. Hündürlük 22px, radius tam.

WF.ui.badge(f, 72, 382, 'Aktiv', { variant: 'secondary' });

Input / Select / Textarea

Anatomiya: Label + Control + Hint. Error halında border accent olur, hint accent mətnə keçir. Select-də sağda chevron var.

WF.ui.input(f, 72, 502, 280, { label: 'Ad, soyad', value: 'Burhan Ağazadə' });
WF.ui.select(f, 72, 602, 280, { label: 'Şöbə', value: 'Rəqəmsallaşdırma' });

Checkbox / Radio / Switch

Anatomiya: 16px kontrol + label. Checked halında primary ink; switch 36×20 track və 14px knob.

WF.ui.checkbox(f, 72, 812, 'Bildiriş', true);
WF.ui.switch(f, 400, 812, 'Aktiv', true);

Avatar

Anatomiya: Image və ya fallback initials. Ölçü: sm 28, default 40, lg 56. Group overlap 10px, ağ ring.

f.av(870, 208, 20, 'BA');
WF.ui.avatarGroup(f, 1000, 208, ['SƏ','BA','NH','RQ'], 14);

Card

Anatomiya: Header (Title + Description) + Content + Footer. Border 1px, radius 8, ağ səth.

WF.ui.card(f, 72, 192, 600, 300, 'Ödəniş gateway',
  '3DS 2.0 keçidi və refund axını');

Alert

Anatomiya: Icon + Title + Description. Destructive variant accent border və accent başlıq işlədir.

WF.ui.alert(f, 72, 568, 600, 72, 'Qeyd', 'Versiya 12 snapshot-u…');

Tabs

Anatomiya: TabsList (muted fon) + TabsTrigger (aktiv ağ pill) + TabsContent. Layihə səhifəsində Overview/Resources/Works.

WF.ui.tabs(f, 348, 192, ['Overview','Resources','Works'], 0,
  { itemPad: 16 });

Table

Anatomiya: Header + Body + Row + Head/Cell. Hücrə mətni, badge və ya avatar+ad ola bilər; sətir ayırıcısı 1px.

WF.ui.table(f, 760, 406, 608, cols, rows);

Breadcrumb

Anatomiya: List + Item + Separator + Page. Son element cari səhifədir və bold göstərilir.

WF.ui.breadcrumb(f, 72, 198, ['Bilik','Sənədlər','Ödəniş axını']);

Dropdown menu

Anatomiya: Trigger + Content + Item + Separator. Dağıdıcı item accent rəngdədir; shortcut sağda göstərilir.

WF.ui.menu(f, 72, 340, 220, [
  { label: 'Profilə bax', shortcut: '⌘P' },
  { label: 'Arxivləşdir', danger: true }
]);

Dialog

Anatomiya: Overlay (dashed stage) + Content + Header (Title + Description) + Footer. Danger halında təsdiq düyməsi accent olur.

WF.ui.dialog(f, 760, 192, 608, 320,
  'Layihəni arxivləşdirək?', 'Ödəniş gateway arxivə köçürüləcək.',
  { confirm: 'Arxivləşdir', danger: true });

Tooltip / Progress / Skeleton / Separator

Anatomiya: Tooltip = trigger + qısa mətn; Progress = track + indicator; Skeleton = yüklənmə formaları; Separator = 1px ayırıcı.

WF.ui.tooltip(f, 92, 610, 'Kopyala');
WF.ui.progress(f, 72, 768, 380, 0.62);
WF.ui.skeleton(f, 500, 768, 160, 12);
WF.ui.separator(f, 760, 850, 608);

Accordion

Anatomiya: Item + Trigger + Content. Eyni anda bir item açıqdır; açıq trigger bold və yuxarı chevron göstərir.

WF.ui.accordion(f, 760, 606, 608, items, 0);
